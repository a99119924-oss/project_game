# О проекте
## Что из себя представляет проект
Простая консольная игра на Python, имитирующая бросок игральных костей. Подходит для развлечения и изучения основ программирования: работы с генератором случайных чисел, обработки пользовательского ввода и построения логики ветвления.
## Технологии и инструменты
- Язык программирования: Python 3.8+
- Стандартные библиотеки: random (для генерации бросков), time (анимационные паузы)
- Платформа: кроссплатформенное приложение (Windows, macOS, Linux)
## Установка и запуск
### Первый способ:
**Предреквизиты**
- Убедитесь, что у вас установлен Python версии 3.8 или выше. Проверить версию можно командой:

> cmd
```
python --version
```
## Инструкция по запуску
- Клонируйте репозиторий:

>bash
```
git clone [ссылка_на_ваш_репозиторий] [каталог]
```
- Запустите скрипт:
>cmd
```
python dice_game.py
```
- Следуйте инструкциям в консоли для начала игры
### Второй способ: 
- Справо от списка найдите раздел "Релизы"
- Перейдите в него
- Скачайте файл main.exe
- Откройте main.exe
